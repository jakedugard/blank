**[Download blank.dmg](https://github.com/jakedugard/blank/releases/latest/download/blank.dmg)** for Mac. Open it, drag blank to Applications. It updates itself from here on.

The other files are for the updater and can be ignored.

## What's new

- **Sign in with Google works.** A sign-in popup (Google, Apple, Microsoft and
  the like) used to open in your default browser, which signed that browser in
  and left the page in blank stuck at its login. It now opens in a small window
  of blank's own, finishes there, and the page behind it is signed in. The
  window is never in a take, and the sign-in is kept between launches.
- **Same-site links stay put.** A link that opens a new tab on the same site
  loads in place instead of leaving for your browser. Links to other sites
  still open in your default browser.
- **The cursor stays in a click-through.** A take with no scroll mode
  selected is one you drive by hand, so the pointer now stays in it. Scroll
  takes still hide it; ••• → Recording → Show Cursor When Scrolling keeps it
  there too.
